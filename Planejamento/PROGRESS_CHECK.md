# Progress Check — Matérias com Aulas Próprias

> Rastreia o progresso real de estudo (aulas + anotações próprias) contra os itens oficiais do Edital CACD 2026, Anexo III. Diferente do `Editais/Conteudo_Programatico.md` (que cobre o edital inteiro via decks gerados de livros de referência), esta página só marca um ponto como completo ou parcial quando existe anotação de aula (`anotações/<matéria>/`) por trás — deck de livro sozinho não conta como ponto estudado aqui.
>
> - ✅ **Completo** — a(s) nota(s) cobre(m) todas as cláusulas do item
> - 🟡 **Parcial** — a nota cobre parte do item; a lacuna está descrita na coluna Observações
> - *(em branco)* — nenhuma anotação de aula ainda
>
> Só existe tabela aqui para matérias com pasta em `anotações/`. Ao processar a primeira aula de uma matéria nova, criar a tabela correspondente nesta página (ver regra em `CLAUDE.md`).
